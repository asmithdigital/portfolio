Folder structure

Everything that matters lives in src/. Hidden pages live in public/portfolio/ and are served as plain HTML.

portfolio/
├── src/
│   ├── assets/images/        ← ALL images go here
│   ├── components/
│   │   ├── SiteHeader.astro
│   │   └── CaseStudyNav.astro
│   ├── data/
│   │   └── projects.ts       ← homepage card data
│   ├── pages/
│   │   ├── index.astro       ← homepage
│   │   ├── about.astro
│   │   └── work/             ← case study pages
│   └── styles/
│       └── case-study.css    ← shared styles
└── public/
    └── portfolio/            ← hidden HTML pages (no Astro processing)
        ├── guide.html        ← this page
        └── work/
            ├── designing-product-interaction.html
            └── product-management.html

How to deploy

Make changes, then run:

cd ~/Documents/Code/portfolio && git add -A && git commit -m "describe change" && git push origin main
Persona images: If you have new versions on your Desktop, copy them first:

cp ~/Desktop/quick-quote-quinn.png ~/Desktop/detailed-donald.png ~/Documents/Code/portfolio/src/assets/images/

Adding images

Step 1 — Move the file

mv ~/Desktop/my-image.png ~/Documents/Code/portfolio/src/assets/images/

Step 2 — Import in the page file

import myImage from '../../assets/images/my-image.png';

Step 3 — Use in HTML

<Image class="aside-img" src={myImage} alt="Describe the image"
  loading="lazy" decoding="async"
  widths={[480,720]} sizes="(max-width:1200px) 30vw, 480px"/>

Step 4 — Push

cd ~/Documents/Code/portfolio && git add -A && git commit -m "Add image" && git push origin main

Homepage cards

Defined in src/data/projects.ts. Each object has:

{
  name: 'UI Design',
  title: 'UI design across...',
  description: 'One or two sentences.',
  background: 'lime',  // lime | cyan | lavender | mint
  href: '/portfolio/work/ui-design',
  image: myImage,
  alt: 'Describe the image',
}
Card order in the array = order on the homepage.

Site header

Edit nav links in src/components/SiteHeader.astro. Every page uses <SiteHeader />.

Case study nav

Add new pages to src/components/CaseStudyNav.astro:

const pages = [
  { href: '/portfolio/work/ui-design', label: 'UI Design' },
  { href: '/portfolio/work/my-new-page', label: 'My New Page' },
];

Shared CSS

All shared layout classes are in src/styles/case-study.css. Import in every case study page:

import '../../styles/case-study.css';

Creating a new page

cp ~/Documents/Code/portfolio/src/pages/work/workshops.astro \
   ~/Documents/Code/portfolio/src/pages/work/new-page.astro

Then: edit content, add to CaseStudyNav, add card to projects.ts, push.

Adding a homepage card

// src/data/projects.ts
import myImage from '../assets/images/my-banner.png';
{
  name: 'Short name',
  title: 'Card heading.',
  description: 'One or two sentences.',
  background: 'cyan',
  href: '/portfolio/work/new-page',
  image: myImage,
  alt: 'Describe the image',

Editing existing content

Change text

Edit text inside <p> and <h2> tags directly in the .astro file.

Swap an image

Add new image to src/assets/images/, update the import line. HTML does not change.

Reorder homepage cards

Reorder objects in the projects array in src/data/projects.ts.
