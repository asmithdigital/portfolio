Folder structure

Everything that matters lives in src/.

portfolio/
├── src/
│   ├── assets/images/        ← ALL images go here
│   ├── components/
│   │   ├── SiteHeader.astro
│   │   └── CaseStudyNav.astro
│   ├── data/
│   │   └── projects.ts       ← homepage card data
│   ├── pages/
│   │   ├── index.astro       ← homepage
│   │   ├── about.astro
│   │   ├── guide.astro       ← this page (not linked)
│   │   └── work/             ← case study pages
│   └── styles/
│       └── case-study.css    ← shared styles

How to deploy

Make changes, then run:

cd ~/Documents/Code/portfolio/backup && git add -A && git commit -m "describe change" && git push origin main
Persona images: Copy from Desktop before deploying if you have new versions:

cp ~/Desktop/quick-quote-quinn.png ~/Desktop/detailed-donald.png ~/Documents/Code/portfolio/backup/src/assets/images/

Adding images

Step 1 — Move the file

mv ~/Desktop/my-image.png ~/Documents/Code/portfolio/backup/src/assets/images/

Step 2 — Import at the top of the page file

import myImage from '../../assets/images/my-image.png';

Step 3 — Use in HTML

<Image class="aside-img" src={myImage} alt="Describe the image"
  loading="lazy" decoding="async"
  widths={[480,720]} sizes="(max-width:1200px) 30vw, 480px"/>

Step 4 — Push

cd ~/Documents/Code/portfolio/backup && git add -A && git commit -m "Add image" && git push origin main

Homepage cards

Defined in src/data/projects.ts. Each object has:

{
  name: 'Working with UI design teams',
  title: 'Working with UI design teams...',
  description: 'One or two sentences.',
  background: 'lime',  // lime | cyan | lavender | mint
  href: '/portfolio/backup/work/ui-design',
  image: myImage,
  alt: 'Describe the image',
}
Card order in the array = order on the homepage.

Case study pages

Copy an existing page and edit it. Every page starts with:

---
import { Image } from 'astro:assets';
import Layout from '../../layouts/Layout.astro';
import SiteHeader from '../../components/SiteHeader.astro';
import CaseStudyNav from '../../components/CaseStudyNav.astro';
import '../../styles/case-study.css';
import myImage from '../../assets/images/my-image.png';
---

Two columns — content left (42rem), image right. Has divider line above.

With image on the right

Standard — 380x255px

Large — 560x387px (personas, UI screenshots)

Site header

Edit nav links in src/components/SiteHeader.astro. Every page uses <SiteHeader />.

Case study nav

Add new pages to the array in src/components/CaseStudyNav.astro:

const pages = [
  { href: '/portfolio/backup/work/ui-design', label: 'Working with UI design teams' },
  { href: '/portfolio/backup/work/my-new-page', label: 'My New Page' },
];

Shared CSS

All shared layout classes are in src/styles/case-study.css. Import in every case study page:

import '../../styles/case-study.css';

Page-specific styles go in a <style> block at the bottom of that page only.

Creating a new page

cp ~/Documents/Code/portfolio/backup/src/pages/work/workshops.astro \
   ~/Documents/Code/portfolio/backup/src/pages/work/new-page.astro

Then: edit content, add to CaseStudyNav, add card to projects.ts, push.

URL = /portfolio/backup/work/new-page matching the filename.

Adding a homepage card

// src/data/projects.ts
import myImage from '../assets/images/my-banner.png';

Editing existing content

Change text

Edit text inside <p> and <h2> tags directly in the .astro file.

Swap an image

Add new image to src/assets/images/, update the import line. The HTML does not change.

Reorder homepage cards

Reorder objects in the projects array in src/data/projects.ts.
